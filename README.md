# RandomBaller

## What will you find in this repository?

First studies focused on the Unity game engine.

As a result, a local multiplayer game was obtained, which is a mixture of Pong and Head Ball 2, where each round is played with a geometric shape with random aesthetic and physical properties.

For that, I had to remember the [basics of C#](https://github.com/tofolo17/Relearning-CSharp), follow an [online course](https://www.domestika.org/pt/courses/716-introducao-ao-unity-para-videogames-2d) and read sections of the [Unity documentation](https://docs.unity3d.com/Manual/index.html).

## O que você encontrará neste repositório?
